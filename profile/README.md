# Bhorosha · ভরসা

On-demand home services for Bangladesh, built on trust: verified providers, hidden phone numbers, fixed prices and a service warranty.

| Repository | What it is |
|---|---|
| `bhorosha-api` | Laravel core: orders, dispatch, ledger, Shopify sync |
| `bhorosha-web` | Next.js admin, support and finance dashboard, public tracking page |
| `bhorosha-mobile` | Flutter Customer, Service Provider and Technician apps |
| `bhorosha-shopify` | Shopify custom app and storefront booking blocks |
| `bhorosha-infra` | Servers, deployment, runbooks, architecture decisions |
| `bhorosha-docs` | PRD, TRD, database, flows, UI and delivery plan |
